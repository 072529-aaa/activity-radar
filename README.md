# 活动雷达 ActivityRadar

> **你的城市活动脉搏。** 不再错过身边任何一场值得参与的 AI 盛会、马拉松赛事与志愿者招募机会。

---

## 这是什么

一个极简、优雅、开箱即用的城市活动聚合工具。把散落在全网的 **AI 厂商线下活动**、**马拉松赛事** 和 **志愿者招募通知** 收进同一个界面，按城市切换、按时间筛选、按关键词搜索——武汉本地活动自动优先突出。

灵感来自 Claude 式的克制美学：暖米白底色、衬线标题、大量留白，让信息本身成为主角。

## 核心能力

- **双赛道聚合** — AI 博览会 / 黑客松 / 创新大赛 + 全马 / 半马 / 迷你跑 / 越野，30+ 场活动持续更新
- **一键定位** — 调用浏览器定位，自动匹配最近城市；也可手动切换 12 个主要城市
- **志愿者追踪** — 每场活动标注招募状态、岗位、人数、截止日期与福利，专属专区一览无遗
- **即时搜索** — 按活动名称、地点、主办方、标签全文检索
- **武汉优先** — 武汉活动卡片红色角标 + 顶部色条，排序可选「武汉优先」
- **离线可用** — PWA 架构，Service Worker 缓存，断网也能浏览已加载的活动

## 像 App 一样使用

本项目是一个 **PWA（渐进式 Web 应用）**，在手机 Chrome 中打开后：

1. 点击浏览器菜单 → **「添加到主屏幕」**
2. 桌面会出现独立图标，点击即全屏启动，与原生 App 体验无异
3. 支持独立联网、定位权限、离线缓存

> 关于安卓安装包：PWA 是目前最轻量化的跨平台方案，无需编译 APK 即可获得类原生体验。如需真正的 `.apk`，可基于本项目用 Capacitor 打包（`npx cap add android && npx cap open android`）。

## 技术栈

- 原生 HTML / CSS / JavaScript — 零依赖、零构建、单文件核心
- PWA — Manifest + Service Worker
- Geolocation API — 浏览器定位
- 字体：Noto Serif SC（标题）+ Noto Sans SC（正文）

## 本地运行

```bash
npx serve .
# 或
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 项目结构

```
activity-radar/
├── index.html      # 主应用（HTML + CSS + JS 单文件）
├── manifest.json   # PWA 清单
├── sw.js           # Service Worker（离线缓存）
├── icon.svg        # 应用图标
└── README.md
```

## 数据说明

活动数据内置在 `index.html` 中，涵盖 2026 年下半年武汉及全国主要城市的 AI 活动与马拉松赛事。数据仅供参考，具体信息请以各活动官方发布为准。

如需接入实时数据源，可在 `activities` 数组处替换为 API 请求。
